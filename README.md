# RxFlow

A scalable digital pharmacy consultation and documentation system for community pharmacists, supporting structured HSE Common Conditions Service (CCS) consultations.

Final Year Project, Yi Jie Lim (20104720), South East Technological University.

## Structure

| Folder | Description |
|---|---|
| `mobile/` | Flutter app (Android + iOS, phone + tablet) |
| `backend/` | Java REST API (coming soon) |

## Running the mobile app

```bash
cd mobile
flutter pub get
flutter run
```
